# Final Prototype

This is a code bundle for Final Prototype. The original project is available at https://www.figma.com/design/rUPftOiiXsKz6rDJpI4oBa/Final-Prototype.

## Prerequisites

This project requires **Node.js 20 or newer** (20, 22, etc.).

If you use [nvm](https://github.com/nvm-sh/nvm):

```bash
nvm install
nvm use
```

If you use [fnm](https://github.com/Schniz/fnm) or [asdf](https://asdf-vm.com/):

```bash
fnm install
fnm use
```

Or install Node 20+ manually from [nodejs.org](https://nodejs.org/).

Verify your version:

```bash
node --version
# should print v20.x.x or higher
```

## Running the code

Run `npm i` to install the dependencies.

Run `npm run dev` to start the development server.
